CV en ligne - Koffi Ehonam Hamenou
Ce dépôt contient mon CV en ligne, conçu en HTML et CSS pour être hébergé sur GitHub Pages.

📑 Aperçu
Ce CV en ligne présente mon parcours professionnel, mes compétences et ma formation dans le domaine du développement web et du marketing digital.

🛠️ Technologies utilisées
HTML5
CSS3
GitHub Pages
🚀 Déploiement
Ce CV est déployé via GitHub Pages et accessible à l'adresse : https://ehonam.github.io/cv-online/

📋 Structure du projet
cv-online/
│
├── index.html          # Fichier HTML principal
├── styles.css          # Feuille de style CSS
├── photo.jpeg          # Photo de profil 
├── qr.png              # QR code GitHub
│
└── README.md           # Documentation du projet
📝 Instructions d'installation
Clonez ce dépôt :
bash
git clone https://github.com/Ehonam/cv-online.git
Naviguez dans le dossier du projet :
bash
cd cv-online
Ouvrez index.html dans votre navigateur pour visualiser le CV.
🔄 Mise à jour
Pour mettre à jour le CV :

Modifiez les fichiers HTML et CSS selon vos besoins
Poussez les modifications vers GitHub :
bash
git add .
git commit -m "Mise à jour du CV"
git push origin main
📱 Responsive
Le CV est conçu de manière responsive pour s'adapter à différentes tailles d'écran.
